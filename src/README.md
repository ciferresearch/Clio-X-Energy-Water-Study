# src

MATLAB functions of the Clio-X Resource Transparency Simulator (version 2.1).

Run everything from this folder:

```matlab
run_all          % reproduce the paper's results -> results/<timestamp>/ (inside src)
cliox_selftest   % 13 checks against hand calculations and statistical theory
cliox_gui        % interactive GUI
```

See the repository README for what is simulated and how each file is used.
